# 四层蒸馏框架 — 方法论详解

## 为什么是四层

常见的博主风格分析停留在「标题怎么写」「开头怎么抓人」「用什么语气」——这些都是 L1 层（语言指纹）。

问题是：**L1 特征换了话题就失效**。一个博主讲「创业」时用短句连击，讲「生活」时可能用长句娓娓道来。如果你只学了他在创业话题下的 L1 特征，切换到生活话题时风格就崩了。

四层框架的核心假设：**底层框架（L4）是跨话题稳定的，上层特征（L1-L3）随话题和内容目标变化**。只要 L4 对了，上层自然对。

## 各层详解

### L4 认知框架

认知框架是博主「看世界的基本逻辑」。它不取决于话题，而是博主个人的思维习惯。

**框架类型库**：

| 类型 | 核心特征 | 典型句式关键词 |
|------|---------|-------------|
| 博弈论 | 所有问题归因于利益/信息不对称 | "本质""博弈""筹码""信息差" |
| 第一性原理 | 回到事物最基本元素重新推导 | "回到本质""底层""根本" |
| 二元对立 | 用二分法制造认知势差 | "两种人""分两类""要么…要么" |
| 反常识 | 以推翻大众认知建立权威 | "你以为…其实""真相是" |
| 时间折叠 | 用时间维度制造洞察感 | "3年前…现在…""这一代人" |
| 层级升维 | 在不同抽象层级间切换 | "在…层面""从…角度看" |
| 进化论 | 用适者生存/淘汰机制解释 | "淘汰""进化""自然选择" |
| 系统论 | 强调要素间的关系而非单个要素 | "系统""正循环""飞轮" |

**操作方法**：
1. 读每条视频的结论部分（通常是最后 2-3 句话）
2. 判断它属于哪种框架类型
3. 统计各类型出现频率
4. 取 TOP2 作为主要框架

### L3 说服策略

亚里士多德三诉诸的现代短视频应用。

**Ethos（身份信用）**：
- "我做了 20 年建材" → 经验性 Ethos
- "我是清华大学 MBA" → 权威性 Ethos
- "我跟 100 个老板聊过" → 数据性 Ethos

**Pathos（情感触发）**：
- "你是不是也有这种感觉" → 共情
- "错过这个窗口期，后悔三年" → 焦虑
- "看完这条，你至少省 10 万" → 希望

**Logos（逻辑证据）**：
- "看这组数据" → 数据型
- "讲一个真实案例" → 案例型
- "因为 A→B→C，所以 D" → 推导型

**操作方法**：
1. 标注每条视频中每一句话属于 E/P/L 中的哪一种
2. 计算总量比例
3. 绘制位置分布（开头 3 句/中间段落/结尾 3 句 各为什么类型）

### L2 话步原型

每一段内容都是一个「动作」。话步分析的本质是：**这条视频由哪些动作组成？动作的顺序是什么？**

**话步类型库**：

| 话步 | 定义 | 示例 |
|------|------|------|
| 钩子 | 开场抓注意力 | "你有没有发现一个现象" |
| 场景 | 设置具体情境 | "我昨天去了一个朋友的工厂" |
| 冲突 | 制造矛盾/张力 | "但他发现了一个问题" |
| 痛点 | 放大痛苦/焦虑 | "每个月亏 50 万" |
| 误判 | 揭示常见错误认知 | "大多数人的第一反应都是错的" |
| 本质 | 点出根本原因 | "核心问题是信息不对称" |
| 案例 | 举具体例子 | "我认识一个老板…" |
| 方案 | 给出解决方法 | "三步解决：第一…第二…第三…" |
| 升华 | 拔高到更高维度 | "这不只是XX的问题，这是YY的问题" |
| CTA | 行动号召 | "你觉得呢？评论区聊聊" |

**操作方法**：
1. 将每条视频按自然段切分
2. 每段标注为一种话步类型
3. 输出话步序列字符串，如 `钩子→痛点→误判→本质→方案→CTA`
4. 聚类相同或相似的序列
5. 取高频序列作为话步原型

**序列相似度计算**：
- 完全匹配：相同序列
- 宽松匹配：允许插入/删除 1 个话步，或替换 1 个同类话步（如「案例」可替换「场景」）

### L1 语言指纹

量化参数，让生成时有具体数字可以约束。

| 参数 | 算法 | 单位 |
|------|------|------|
| 平均句长 | 总字数 / 总句数 | 字 |
| 句长标准差 | std(每条句子字数) | 字 |
| 反问频率 | 反问句数 / 总句数 | % |
| 排比密度 | 排比结构数 / 总段落数 | 次/段 |
| 高频词 | TF-IDF 或纯频率 TOP20 | 词 |
| 口语化指数 | (语气词+口语连接词) / 总词数 | % |

## 跨话题稳定性验证

蒸馏完成后，用以下方法验证 L4 框架的可迁移性：

1. 选 3 个目标博主从未涉及过的话题
2. 只给 L4 框架 + L3 说服策略（不给 L1-L2），生成文案
3. 检查是否「感觉像」
4. 如果像 → L4 框架有效
5. 如果不像 → 回到 L4 重新分析
