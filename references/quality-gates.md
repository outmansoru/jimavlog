# 质量控制 — 三重门

蒸馏不是「AI 分析一次就完了」。三道门确保产出的 Skill 不是幻觉。

## Gate 1：频率门

**原则**：高频模式才可信，低频模式是噪声。

### 阈值

| 指标 | 严格模式（推荐） | 宽松模式 |
|------|----------------|---------|
| L4 认知框架 | ≥ 3 条视频为同一框架 | ≥ 2 条 |
| L3 说服配比位置规律 | ≥ 70% 视频一致 | ≥ 50% |
| L2 话步序列 | ≥ 30% 视频出现 | ≥ 20% |
| L1 高频词 | TF-IDF 值 > 均值+1σ | > 均值 |

### 低于阈值的处理

- 标记为「🔍 疑似」
- 放入 Skill 的「创作禁区」章节作为参考
- **不进入** Skill 的核心 Prompt

## Gate 2：区分度门

**原则**：如果两个博主蒸馏出完全相同的认知框架，说明分析粒度不够。

### 操作

1. 每蒸馏一个新博主，与风格库中已有的所有博主比对 L4 框架
2. 如果框架类型冲突 → Deepen：在现有框架类型后加次级标签

### Deepen 示例

```
博主A：博弈论框架 → 深化 → 博弈论·零和型（强调竞争关系）
博主B：博弈论框架 → 深化 → 博弈论·合作型（强调共赢策略）
```

### 区分度不足的信号

- L4 框架相同 → 检查：两个博主真的用同一种思维模型吗？还是框架类型库不够细？
- L2 话步序列相同 → 可能没区分：是平台通用模板还是博主个人风格？

## Gate 3：置信度标注

**原则**：不假装 100% 确定。让 Skill 的使用者知道什么是有把握的，什么是推测。

### 标注规则

| 等级 | 条件 | 标注符号 | 示例 |
|------|------|---------|------|
| 高 | ≥ 70% 视频中一致 | ✅ 确定 | ✅ L4认知框架：博弈论（18/20条，90%） |
| 中 | 40-69% 视频中一致 | ⚠️ 倾向 | ⚠️ L2话步序列：钩子→冲突→方案（12/20条，60%） |
| 低 | 20-39% 视频中出现 | 🔍 疑似 | 🔍 L1高频词："降维打击"（6/20条，30%） |

### 置信度分布目标

- ≥ 60% 维度为「高」或「中」→ Skill 可用
- < 60% → 说明样本量不足或博主风格本身不稳定，建议增加样本

---

## 门控流程

```
分析完成
  │
  ├─ Gate 1: 频率过滤
  │   ├─ 高频 → 通过
  │   └─ 低频 → 标记「疑似」→ 进入备用池
  │
  ├─ Gate 2: 区分度检查
  │   ├─ 无碰撞 → 通过
  │   └─ 有碰撞 → Deepen → 重新检查
  │
  └─ Gate 3: 置信度标注
      ├─ ≥ 60% 高/中 → 进入 Skill 生成
      └─ < 60% → 提示增加样本
```
